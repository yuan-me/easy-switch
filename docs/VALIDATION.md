## 已知实施差异

React 保持列表组件与行 key，用定时扫描更新数据，因此旧 WPF 的 ObservableCollection Reset/文件 watcher 实现没有原样照搬；需要验证新界面的选择、搜索、阅读位置在刷新和页面往返后保持。更新安装目前要求完整退出 Codex，比仅检查瞬时写入更保守。旧实验性页面恢复开关在设置中保持关闭，阅读位置使用 Easy Switch 自身记录。

## 2026-09-29 虚拟机追加结果

- 真实 Sub2API 纯 API 配置已经通过新版切换流程重新应用；加密操作备份已生成，全部会话非元数据正文摘要保持不变。requires_openai_auth=false、actor header 正确，未添加 image_generation feature。实际生成并显示图片已由用户在虚拟机 Codex 新会话确认通过（2026-09-29）。
- 当前 Codex 的分页/回退历史会同线程多文件共存。新增识别、继承正文读取、跨目录归档与依赖删除保护。元数据等长写入保留 history_base 及数据库字节偏移；若新值超过原行容量，明确拒绝操作。任意长度项目迁移的偏移重建尚未实现，不能宣称全部会话迁移已验收。
- 修正 MSIX 辅助命令行入口误识别，并排除安装目录下的独立 CLI；修正 Windows 回环连接失败确认超时，回环认证请求不使用系统代理。
- 按用户反馈采用 CC Switch 参考的三色抽象图标和浅色圆角框（无字母），删除装饰性页面文案。

- 官方模式与混入模式未完成：虚拟机尚无保存的官方身份，自动 Ctrl+Q 退出未成功时已安全停止、未改写配置；等待用户正常退出后继续。

## 上传前精简与性能复测

- 详情与导出复用已有 Scanner 缓存，仍重新校验文件大小、修改时间、目录边界与链接；写操作继续使用原有完整安全流程。批量选择使用 HashSet，避免逐行遍历选择列表。
- 删除模型发现、恢复流程中的重复配置读取；会话刷新合并尚未完成的同类请求；空搜索跳过字符串转换；未增加运行时依赖。
- 诊断共用逐块响应读取，超过 4 MB 时立即拒绝，响应头之后仍可取消；真实本地 HTTP 测试覆盖正常列表、503、超限和取消。
- 侧栏使用同一设计源生成的 128px 图标，资源从 867,639 字节降至 15,653 字节。签名安装包从约 5.38 MiB 降至 4.58 MiB。
- `node scripts/performance.cjs before|after` 使用相同的 500 个合成 JSONL、每文件 40 条事件，各测 7 次详情调用。详情中位数 162.287 → 61.672 ms（约减少 62%）；启动 569 → 629 ms、首次扫描 210 → 210 ms，没有测出改善。此为当前机器与样本的结果，不代表所有会话规模。
- 本地证据：`artifacts/performance-before.json`、`artifacts/performance-after.json`、`artifacts/icon-audit/report.json`；VM 证据留在父工作区的私有 `artifacts/vm-test`。正式发布门槛仍以上方未勾选项为准。
